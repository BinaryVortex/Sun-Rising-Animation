# Sun Rising Animation

A beautiful and serene sun rising animation built using HTML and CSS. This project creates a calming visual experience of a sunrise over a scenic landscape, featuring animated elements like the sun, clouds, birds, and hills.

## Features

- **Pure CSS Animations**: No JavaScript required, making it lightweight and fast.
- **Scenic Elements**: Includes background images of hills, clouds, and birds for a peaceful morning atmosphere.
- **Responsive Design**: Adapts to different screen sizes.
- **Simple and Elegant**: Easy to understand and modify.

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/BinaryVortex/Sun-Rising-Animation.git
   ```
2. Open `index.html` in your web browser.

## Files

- `index.html`: The main HTML structure.
- `style.css`: Contains all the CSS for styling and animations.
- `hill.png`, `cloud.png`, `birds.png`: Background images used in the animation.
- `Screenshot 2024-07-11 055516.png`: A screenshot of the animation.
